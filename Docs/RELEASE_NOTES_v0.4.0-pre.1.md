# v0.4.0-pre.1 — Source prototype & portfolio baseline

First tagged source milestone for **SORA: After the Rain**, a third-person convenience-store and life-simulation project set in rainy Tokyo.

## Included

- Owner-supplied v0.4 Unity/C# prototype and canonical game-design document.
- Two switchable twin protagonists, shared store data, draft/confirm POS, inventory operations, simple customer relations, JSON quicksave and procedural primitive environment.
- Pinned Unity `6000.3.7f1`, URP `17.3.0`, stable asset GUIDs and Editor setup/scene/build automation.
- Five authored EditMode integrity tests; offline source-validation CI; optional manual licensed Windows workflow.
- English, Vietnamese and Japanese READMEs, architecture and QA documentation, roadmap, contribution templates and original project identity artwork.

## Validation status

Offline structure/JSON/GUID checks are verified. **Unity import/compile, EditMode execution, Play Mode, rendering and Windows builds are NOT RUN.** This is a pre-release source milestone, not a validated playable game. GitHub's source ZIP/tarball contain the repository; no Windows executable is attached.

## Open the source

Clone the repository, add it in Unity Hub and use Editor `6000.3.7f1`. Run **SORA > 0. Configure Prototype Project**, then **SORA > 1. Generate Demo Scene**. Follow the README and `Docs/CI_SETUP.md`; first-run Editor verification remains required.

## Next milestone

Complete the first real Unity acceptance: resolve imports, run tests, inspect gameplay, commit generated configuration and produce the first validated Windows build. Store transaction/save hardening, real NPC work, quests and production art follow later.
