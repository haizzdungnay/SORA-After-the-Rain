## LinkedIn post — English

I'm sharing the first source milestone of SORA: After the Rain, an indie project about two university-student twins starting a new life in Tokyo and working at the same convenience store.

The engineering question I'm exploring is how to switch protagonists while keeping one store economy consistent and each character's social progress separate. The source includes a character-switching prototype, basic POS/inventory and relationship state, plus five authored EditMode tests and GitHub Actions source checks.

I've also documented the architecture, tradeoffs and roadmap in English, Vietnamese and Japanese. This is an early source prototype developed with AI assistance. Unity compile, test execution, gameplay capture and a validated Windows build are the next acceptance step.
